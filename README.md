# Selene UI Tests

Проект содержит **UI‑тесты для веб‑формы** с использованием Python‑фреймворка Selene.

---

## 📌 Обзор

Этот репозиторий предназначен для:

- практики работы с Selene
- примера тестирования формы на сайте [DemoQA](https://demoqa.com/automation‑practice‑form)


Тест покрывает:
- ввод полей
- выбор радиокнопок
- работа с календарем
- загрузку файлов
- проверку результата в pop‑up

---

## 🛠 Стек

- Python 3.12  
- Selene
- pytest
